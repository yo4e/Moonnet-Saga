## Current rule

現時点では Moonnet Saga は **All Rights Reserved**。

CC BY-SA 4.0等は将来構想であり、このディレクトリの追加によってライセンスは変更されない。

また、商業出版社から商業出版として刊行された作品は、原則としてMoonnet Sagaの本文収録・オープンライセンス対象にしない方針です。
