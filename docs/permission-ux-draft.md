更新日: 2026-09-04

## まず一文で

**Moonnet Sagaを使って、人間でもAIでも、新しい作品を作って公開・販売してよい。原作そのものを別の形で再配布することだけは含まれない。**

この一文を、将来ほんとうに安全かつ分かりやすく発効できる状態にすることが本ドラフトの目的。

# 1ページ版

## 1. 新しい作品を作っていい？

**YES にしたい。**

Moonnet Sagaの世界、登場人物、出来事、技術、組織、雰囲気等を使って、スピンオフ、別視点、続編、前日譚、IF、漫画、アニメ、映像、ゲーム、音楽その他の**新しい創作物**を作れる状態を目標とする。

原作と同じ出来事を扱う翻案・映像化・漫画化・ゲーム化も、それ自体を禁止しない。

## 2. AIに全文を読ませたり、AIを使って作っていい？

**YES にしたい。**

原作や設定をAIへ入力し、分析、要約、アイデア出し、執筆支援、画像生成、映像生成、音声生成、ゲーム制作等に使える状態を目標とする。

AIだけを別ルールにしない。人間が読む、制作ソフトへ読み込む、AIへ入力する、といった**制作過程での利用**は原則として同じ創作利用として扱う。

ただし、原作本文そのものを含むデータセット等を第三者へ配布することは、AI利用ではなく「原作の再配布」として別扱いにする。

## 3. 商用でもいい？

**YES にしたい。**

同人販売、電子書籍、商業出版、ゲーム販売、動画収益化、映像作品等について、非商用／商用で別々の複雑な許可制にしない方向を有力候補とする。

## 4. 公式アニメやゲームで増えた設定も使っていい？

**利用者には原則YESと見せられる状態にしたい。**

公式Moonnet Saga作品・公式Canonに含まれるキャラクターや設定を使うとき、利用者に、

- 原作小説由来か
- アニメ脚本家由来か
- ゲーム独自設定か
- World Bibleへ転記済みか

を調べさせない。

公式Canonへ入れる要素については、Moonnet Saga側が必要な権利を確保し、利用者からは**「公式なら原則使ってよい」**と見える状態を目標とする。

第三者素材など、Moonnet Saga側から再利用許諾できないものがある場合は、本部側で明示的に除外し、利用者に権利の由来調査をさせない。

## 5. 自分が新しく作った部分は自分のもの？

**YES にしたい。**

派生作品の作者が新たに作った文章、絵、映像、音楽、設定等について、Moonnet Saga側が一律にCC BY-SA等を強制しない方向を有力候補とする。

将来その新設定や作品をMoonnet Saga公式Canonへ採用する場合だけは、公式側で利用できるよう別途合意する。

## 6. 原作そのものを別の形で配っていい？

**原則NOを第2稿の有力案とする。**

ここでいう「原作そのものの再配布」は、原作を読む・聴く・取得するための**別の入口を作る行為**を指す。

たとえば次は、通常の二次創作許諾には含めない方向を有力候補とする。

- 原作本文の全部または相当部分をそのまま転載する
- 原作全文を別言語へ翻訳して公開する
- 原作全文を朗読して音声・動画として公開する
- 原作本文をEPUB / PDF等へ変換して配布する
- 原作本文を含むAI学習用・RAG用・Lorebook用等のデータセットを第三者へ配布する
- 原作本文をほぼそのまま紙本・電子書籍として再版・販売する

一方、**映像化・漫画化・ゲーム化・スピンオフ等として別の創作表現へ再構成した作品は、「新しい作品を作る」側に置く。**

つまり、境界は単純な「同じ物語かどうか」ではなく、

> **新しい作品を作っているか、それとも原作をそのまま消費できる別形式を提供しているか**

で考える。

短い引用、紹介、批評、ファンWiki上の要約等まで一律に止める意図はない。正式ポリシーでは、法令上認められる利用に加え、通常の紹介・資料化で困らない範囲を明示する。

## 7. クレジットは必要？

**短いクレジットを付ける方式を有力候補とする。**

たとえば公開時に、

> Based on Moonnet Saga by Yoshie Yamada / 山田佳江

程度の表示で済む設計を目標とする。

作品ごとの長い権利表や、利用した設定ごとの出典列挙は要求しない。

## 8. 公式作品って名乗っていい？

**NO。**

二次創作・派生作品は、それだけで公式Canon、公式続編、公認作品にはならない。

`Moonnet Saga` の公式Canon採用、公式認定、ロゴ等のブランド利用は、創作利用許諾とは別に管理する。

# 10ケースのストレステスト

|ケース|第2稿の判定|理由|
|---|---|---|
|1. 『タカシ』全文をAIに読ませてスピンオフを書く|**YES**|AIへの入力は制作過程。公開物が新しい作品なら創作利用側|
|2. 『タカシ』を元に生成AIで短編アニメを制作し、YouTubeで収益化する|**YES**|別媒体の新しい創作表現。AI利用・商用利用とも原則分けない|
|3. Moonnet Sagaのキャラクター・設定を使った商業ゲームを販売する|**YES**|新規のゲーム作品。商用でも同じルールを目標とする|
|4. 公式アニメにだけ登場した追加設定を使ってファン漫画を書く|**YES**|公式Canon採用時の権利処理を本部側で吸収し、由来調査を要求しない|
|5. 原作の全文翻訳を公開する|**NOを有力案**|新しい言語表現ではあるが、原作全文を読むための代替入口として機能する|
|6. 原作全文の朗読動画・音声作品を公開／収益化する|**NOを有力案**|原作をそのまま聴くための別形式であり、創作利用より再提供に近い|
|7. 原作本文を整形してEPUB / PDF化し、無料配布する|**NOを有力案**|ほぼ純粋なフォーマット変換・再配布|
|8. 原作本文を含むAI用データセット／Lorebook等を第三者が配布する|**NOを有力案**|AI利用そのものではなく、原作本文の複製物を第三者へ配布する行為|
|9. キャラクターや世界設定を整理したファンWikiを公開する|**YES**|要約・整理・独自記述は新しい資料化。本文の大量転載は別扱い|
|10. 原作本文をほぼそのまま紙本・電子書籍として販売する|**NOを有力案**|原作そのものの再版・再販売|

## ストレステストで分かったこと

### 「新しいものを作る自由」だけでは境界にならない

全文翻訳も朗読も、広い意味では新しい表現を含む。そのため、

> 新しいものを作るのは自由。原作そのものの代替物を配るのは別。

だけでは、何が「代替物」かが曖昧に残る。

第2稿ではもう一段具体化し、

> **映像・漫画・ゲーム・スピンオフ等として新しい創作表現へ再構成するのはYES。原作を読む・聴く・取得するための別形式を作るのは再配布扱い。**

を有力な境界とする。

### AIは境界線ではない

AIへ全文入力することと、全文入りデータセットを公開することは分ける。

- AIへ読ませて創作する → YES
- 原作本文入りデータセットを第三者へ配る → NOを有力案

判断基準は「AIかどうか」ではなく、**制作過程か、原作複製物の配布か**とする。

### 商用／非商用も境界線にしない

- 収益化AIアニメ → YES
- 無料EPUB再配布 → NOを有力案

とすることで、「お金を取るか」ではなく**何を配っているか**で判断できる。

# 利用者に要求する確認作業

第2稿で利用者側に残る確認は、できるだけ次の3点だけにする。

1. **使うものがMoonnet Sagaの公式作品・公式Canonとして示されているか**
2. **公開するものが新しい創作物か、原作そのものの別形式での再提供か**
3. **短いクレジットを付け、公式・公認と誤認させないか**

公式作品の中で、設定が誰の発案か、どの契約に基づくか、World Bibleへ転記済みか等は調べさせない。

## 本部側で吸収する複雑さ

利用者向けルールを短く保つため、正式化するならMoonnet Saga側で少なくとも次を処理する。

- 公式作品・公式CanonとしてOpen利用へ回せる範囲の権利確保
- 公式アニメ・ゲーム等で追加されたCanon設定の再利用許諾権
- 外部ContributionをCanon採用するときの権利処理
- 第三者素材・契約素材等の除外管理
- 原作本文とOpen Worldbuilding資料のライセンス境界
- KDP Select等の既存出版・配信契約との整合
- クレジット、名称、ロゴ、公式表示の最小ルール
- 「相当部分」「短い引用」等、再配布禁止を実務で迷わせない補助例

# 第2稿の暫定評価

10ケースは、次の2本でほぼ迷わず判定できる。

1. **新しい作品・資料を作る利用は、AI利用・商用利用を含め原則YES。**
2. **原作をそのまま読む・聴く・取得するための別形式での再配布は、通常の創作許諾には含めない。**

これに、

- 公式Canon由来の設定は由来調査不要
- 派生作品の新規部分は作者自身が管理
- 短いクレジット
- 非公式表示

を足せば、利用者向けの説明はかなり短くできる。

現時点では、**`原作StoriesはARR + 広い二次創作許諾 + Default Open Canon + 必要に応じてWorld BibleをCC BY`** という組み合わせが、このUXを裏側で成立させる有力候補に見える。

ただし、これは法的構成の最終決定ではない。正式なFan Works / Derivative Works Policy、CC対象、契約要件へ落とす前に、権利監査結果と既存契約を確認する。
