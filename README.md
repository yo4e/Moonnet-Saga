# Moonnet Saga

> [!WARNING]
> **このリポジトリには、ムーンネットサーガ各作品のネタバレが含まれます。**
> 世界設定を記録する性質上、人物の正体、技術の仕組み、作品内で後から明かされる事実なども区別せず扱います。

**Moonnet Saga** は、山田佳江によるSF作品群と、その世界・技術・時代・宇宙観を記録していくプロジェクトです。

このリポジトリは現時点では、シリーズの設定資料をまとめる **living atlas（成長する観測地図）** として機能しています。将来的には、原作・設定・機械可読データ等を人間やAIが読み継ぎ、新しい物語や別の branch を生み出せる共有創作宇宙へ開いていくことを構想しています。

## Open Story IP for Humans and AI

Moonnet Saga は、単に「読むための小説シリーズ」だけではなく、**人間とAIの双方が新しい作品を生み出すために利用できる Open Story IP** へ育てていくことを目指しています。

### Open Story IP とは

このプロジェクトでは **Open Story IP** を、**権利者が指定した物語・世界設定・キャラクター・用語・関連データ等をオープンライセンスで公開し、第三者が明示された条件のもとで再利用・改変・再配布・派生創作・商用展開できる物語IP** と定義します。人間による創作だけでなく、AIをコンテキスト、Lorebook、キャラクターデータ、生成支援等に利用する創作も想定します。

> **Open Story IP:** a fictional IP whose designated stories, worldbuilding, characters, terminology, and related data are intentionally opened by the rights holder so that others — including AI-assisted creators — can reuse, adapt, redistribute, and build commercial or non-commercial derivative works under an explicit open license.

これは現時点で確立された業界標準用語であると主張するものではなく、**Moonnet Saga がこの構想を表すために用いるプロジェクト上の定義**です。

**Concept definition: Yoshie Yamada / Moonnet Saga — 2026-08-28**

将来的にCC BY-SA 4.0の対象として明示された作品・設定については、この世界を素材として、小説、漫画、イラスト、映像、音楽、ゲーム、翻訳、スピンオフ、別世界線などの派生作品を制作できる形を想定しています。ライセンス条件を満たす限り、商用利用も可能にする方針です。

AIによる利用も想定しています。たとえば、世界設定や人物情報をAIのコンテキストとして読み込ませる、Lorebookやキャラクターデータを作る、設定をもとに新しい物語・ゲーム・会話体験を生成するといった使い方です。

将来的には、文章だけでなく年表、人物関係、用語集、JSON/YAML、Lorebook等の機械可読データも整備し、**「この世界を使って、あなた自身の作品を作ってください」** と言える創作基盤を目指します。

### 派生作品と公式性

将来オープン化したMoonnet Sagaからは、作者自身が制作しない種類の作品や、作者自身とは異なる価値観・表現を含むbranchが生まれる可能性があります。成人向け、暴力的、政治的、宗教的その他の表現を含む派生作品についても、適用される法律・ライセンス・利用サービスの規約等の範囲内で、各制作者が独立して制作するbranchとして扱います。

**派生作品が存在することは、山田佳江またはMoonnet Sagaが、その内容・思想・表現を賛同、推奨、公認していることを意味しません。** また、派生作品は明示的にCanonへ採用された場合を除き、Moonnet Sagaの公式作品・公式設定ではありません。各branchの内容と公開・配布については、それぞれの制作者が責任を負います。

> **Read it. Fork it. Build your own branch.**

※ 現時点ではまだオープンライセンスへの移行前です。実際に利用できる対象と条件は [`RIGHTS.md`](RIGHTS.md) で明示します。

## このリポジトリについて

ムーンネットサーガには、最初から完成した年表や設定資料があるわけではありません。

作品が書かれるたびに、その時代、その世界、その技術について新しいことが見えてきます。したがって、このリポジトリは「正解を先に決める百科事典」ではなく、**作品によって観測されたものを記録し、まだ見えていない領域は空白のまま残す地図**として運用します。

> 空白は欠落ではなく、まだ作品によって観測されていない領域です。

年代、技術史、宇宙間の関係には、意図的に曖昧な部分があります。新しい作品によって解像度が上がったり、以前の理解が更新されたりすることがあります。

## おおまかな特徴

- インターネット以後の大規模ネットワーク「ムーンネット」
- 月面サーバーを含む地球外情報インフラ
- AR世界・データとして存在する住人
- 多元宇宙と世界間境界
- 人格・知性・身体を技術的に扱う社会
- 人間が作った知性と、人類のその後

これらすべてが、すべての作品に登場するわけではありません。同じ世界史の別の時代、あるいは多元宇宙上の別世界として、互いに遠く離れた作品もあります。

## 記録の確度

設定資料では、情報を次のような確度で扱います。

- **confirmed** — 作品内で確認できる設定
- **author-note** — 作者が現時点で把握している設定・年代感
- **provisional** — 新作や壁打ちで検討中の設定
- **unknown** — まだ決めていない／作品からは分からない領域

`provisional` や `unknown` は、埋めること自体を目的にしません。

## 将来像

Moonnet Saga を、人間だけでなくAIも読み継ぎ、新しい物語や別の branch を生み出せる **長く継承される共有宇宙** へ開いていく構想があります。

山田佳江が必要な権利を保有する **Moonnet Saga の作品・設定資料のうち、明示的に対象として指定したもの** については、将来的に **CC BY-SA 4.0** を基本ライセンスとして公開し、二次創作、スピンオフ、翻訳、ゲーム化、商用利用、AIへのコンテキスト投入やLorebook化などを広く可能にする方向を検討しています。

**山田佳江の他の作品は、同じ作者による作品であるというだけではこのオープンライセンスの対象になりません。** Moonnet Saga に属さない作品、またはCC BY-SA 4.0の対象として明示されていない作品は除外します。

また、年表、人物関係、用語、設定、JSON/YAML等を整備し、人間だけでなくAIシステムにとっても扱いやすい **AI-readyな物語世界** として公開していく可能性があります。

オープン化しても、すべての派生作品が公式Canonになるわけではありません。独自branchの創作は歓迎しつつ、公式Canonへの取り込みは選択的に行う想定です。

> Git的にいえば、**forkは歓迎、Canonへのmergeは選択的**。

この構想はまだライセンス変更そのものではありません。対象範囲や権利関係を確認したうえで、実際に移行する場合は条件を明示します。詳細は [`RIGHTS.md`](RIGHTS.md) を参照してください。
