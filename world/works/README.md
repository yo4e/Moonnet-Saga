# Work Observations

このディレクトリには、各作品から観測できる世界設定・技術・年代・人物関係などを記録します。

`WORKS.md` は作品カタログに徹し、作品ごとの詳細な設定観測はこちらへ分離します。

設定情報の確度は次のように扱います。

- `confirmed` — 作品本文で確認できる
- `author-note` — 作者が現時点で把握している
- `provisional` — 新作や壁打ちで検討中
- `unknown` — まだ決めていない／作品からは分からない

この確度は、作品そのものがMoonnet Sagaに属するかどうかを示す `confirmed / possible / excluded` とは別軸です。
