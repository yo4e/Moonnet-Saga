# 『タカシ』観測記録

- Saga status: `confirmed`
- status: existing short fiction
- approximate era: 2100年より後くらい（author-note）

## Observations

- `confirmed`: ムーンネット創始者の孫「タカシクロダ」の細胞から、最初の「末裔」が作られ、その後同じ細胞から複数パターンの末裔がバイオプリンティングされる。
- `confirmed`: 末裔は人間から作られたが、人間とは異なる存在として自己認識している。
- `confirmed`: 末裔には本来性差がなく、必要に応じて身体改造が可能。
- `confirmed`: 末裔は人間より高い知性を持ち、人間側がその知性を恐れて脳にリミッターをかけることがある。
- `confirmed`: 末裔は「人間に寄り添い助けるため」に作られた存在で、人類がゆるやかに衰退していく未来を認識している。
- `confirmed`: 末裔は人類の死後に自分たちが暮らす場所として「サイアン」を作っている。サイアンの環境は人間には致命的だが、末裔は高速な細胞再生によって生存できる。
