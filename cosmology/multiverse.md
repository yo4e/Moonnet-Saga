# Multiverse / World Boundary

ムーンネットサーガに接続しうる多元宇宙と、ユニバース間境界についての観測記録。

## 『アンフォールドザワールド』での呼称

status: confirmed / author-note

『アンフォールドザワールド』では、多元宇宙構造を **ハニカムユニバース** と呼ぶ。

この名称は同作側の呼称であり、サーガ全体の絶対的な正式名称とはしない。同じ構造が、別時代・別ユニバース・別の研究領域では異なる名称で呼ばれていてよい。

## ナニガシ

status: confirmed / author-note

『アンフォールドザワールド』では、ユニバース同士を隔てる「壁」が **ナニガシ** という意思体で構成されている。

- ナニガシは単に壁の中に住んでいる存在ではなく、壁そのものを構成する意思体。
- ときどきナニガシが境界からどちらか一方の世界へ抜け出すことがある。
- ナニガシが抜けると、その場所には境界の欠損＝穴が生じる。
- 穴が生じることで、本来分離されていた二つのユニバースが接続しかける。
- したがって「ナニガシが世界へ出現すること」と「ユニバース間に穴が開くこと」は同じ現象の表裏にある。
- 『アンフォールドザワールド』では、出てきたナニガシを捕まえることが物語上の重要な出来事になる。

ナニガシが何を考え、なぜ境界から抜けるのかなど、意思体としての詳細は現時点ではここで固定しない。

## 技術史への接続候補

status: provisional

『十＋十』の時代には、かつて『アンフォールドザワールド』で「ナニガシ」と呼ばれたものと同種の境界意思体が、別の工学的名称で認識・統制されている可能性がある。

その場合、後世の branch 技術は「無から別宇宙を生成する技術」というより、**意思を持つ世界間境界を局所的・可逆的に制御する技術**として理解できる。

考えられる対応関係：

- 境界意思体を局所的に移動・変形・固定する
- 境界に制御された接続面を作る
- 近傍の可能世界を branch として成立／選択／接続する
- 用途終了後に境界を再形成して branch を閉じる
- 人格・経験情報の統合技術と組み合わせて merge を行う

この技術がムーンネット由来の情報技術とどの時点で接続するかは未確定。

## branch failure と過去の怪異

status: provisional

もし上記の接続を採用するなら、後世の「branch termination failure」のような事故は、『アンフォールドザワールド』の時代に起きていた「ナニガシが抜け、穴が開き、世界がつながりかける」現象と、本質的に同じものになりうる。

時代が違えば、同じ自然現象が怪異・生物現象・宇宙論・工学用語として別々に記述されていてよい。

## AIとの関係

status: provisional

『十＋十』では、人間がAIを「新しい神」に近い存在として扱う世界観を検討している。

もしAIが境界意思体を統制し branch を運用するなら、そのAIは無から世界を創造するというより、**世界を隔てる意思体を制御し、可能世界を人間のために切り分ける存在**になる。

ただし、境界意思体そのものはAIより古い宇宙論的存在でありうる。AIが世界を制御できても、宇宙の最上位存在とは限らない。

この関係は『十＋十』用の暫定設定であり、今後の作品によって変更してよい。
